# Data

This folder contains **five  CSV tables** from the reference simulation run. They are supplied for reprodution. The main R code generates these tables; the initial parameter choices are documented in **Supplementary Table S2** of the manuscript.

| File | Contents |
| --- | --- |
| [`size_class_parameters.csv`](size_class_parameters.csv) | Simulation parameters by body-size class: species pool, abundance, spatial clustering and population size. |
| [`baseline_iteration_results.csv`](baseline_iteration_results.csv) | Pre-disturbance measurements per iteration and body-size class, including richness, beta diversity, abundance and sampling diagnostics. |
| [`baseline_summary.csv`](baseline_summary.csv) | Pre-disturbance sampling diagnostics summarized across iterations (mean and 2.5th/97.5th percentiles). |
| [`iteration_results.csv`](iteration_results.csv) | Post-disturbance diversity measurements and mortality effects for each iteration, body-size class and mortality scenario. |
| [`scenario_summary.csv`](scenario_summary.csv) | Post-disturbance mortality and diversity changes summarized across iterations for each scenario and body-size class. |
