# thanos.snap

**What would happen to animal diversity if 50% of individuals disappeared?**

Inspired by the fictional *Thanos snap* in the Marvel universe, **thanos.snap** uses spatial simulations to explore how different distributions of individual-level mortality influence species diversity across animal body sizes. This is a hypothetical modelling exercise, not an analysis of an observed mortality event.

## Design
The supplied analysis session used **R 4.4.3** and packages including 'mobsim', 'ecopart', 'spatstat', 'vegan', 'dplyr', 'tidyr', and 'ggplot2'. Package versions and execution instructions should be documented alongside the scripts. Since our implementation is computer intensive code use 'paralel' for processing parallelization.
The simulations compare four scenarios with a nominal **50% mortality** disturbance:

1. **Regional fixed 50%:** half of individuals are removed at the regional scale.
2. **Local fixed 50%:** half of individuals are removed within local sampling units.
3. **Probabilistic individual 50%:** each individual has a 50% mortality probability.
4. **Sub-regional event:** mortality is concentrated unevenly across space.

Responses include realized mortality, changes in local species richness, changes in regional species richness, and changes in net Whittaker beta diversity.

The supplied run summary reports **25 body-size classes (0.1 g to 100 kg)**, **1,000 iterations**, and **30 non-overlapping, occupied sampling quadrats per iteration**. Initial ecological and simulation parameters are documented in **Supplementary Table S2** of the associated study. Please consult that table for the full parameter definitions and assumptions.

Modelled communities, iteration-level outputs, summary tables, and spatial examples are igenerated by the **R scripts**. Main results stored as  `.csv` files are included in the data folder  in this repository package. Initial model parameters are also described in **Supplementary Table S2**.
